# 03 — User Flow

> Not software. An experience.
> Every journey is designed to feel like a peaceful walk through a storybook — sunrise to sunset.

---

## The Experience Arc

```
Sunrise
   ↓
Welcome
   ↓
Choose How We Worship
   ↓
Meet Each Other
   ↓
Discover Together
   ↓
Reflect Together
   ↓
Discuss Deeply
   ↓
Grow Together
   ↓
Sunset / Summary
```

Each chapter has a **feeling** it should evoke. The UI, animations, and sounds all serve that feeling.

---

## Chapter-by-Chapter Journey

## Remote Mode Differences

In remote mode, the flow is identical, but:

- **Chapter 2:** Both devices must connect before proceeding.
- **Chapter 3:** Turns switch automatically. The non-active player sees a "Waiting for [name]..." banner.
- **Chapters 4-6:** State syncs in real-time. Both see the same clue, scenario, or card.
- **Chapter 7:** Both see the same summary.

---

## Edge Cases

| Situation | Behavior |
|-----------|----------|
| Guest joins mid-session | Guest receives current step + state via sync messages |
| Connection drops | Both see "Partner disconnected." Banner; can reconnect |
| User refreshes page | Names + mute persist; journey resets to Chapter 1 |
| Invalid room code | Error message: "Could not connect to room code. Please check the code." |
| Host leaves room | Guest sees disconnected state; can rejoin |
| Single mode + remote code in URL | URL params auto-fill remote mode |
